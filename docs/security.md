## BK — revision coercion integrity

A JSON fractional revision must not silently become a different optimistic-concurrency value. Three legacy Core HR Long inputs now use decimal-preserving web models and exact nonnegative conversion. Invalid revisions fail before the use case with no business writes; valid inputs still undergo existing current actor, record/field and tenant checks. Tests cover postal/onboarding role and cross-tenant denial plus full-suite policies. This closes the reproduced coercion defect in these routes; it is not an exhaustive transport/security review or release acceptance.
