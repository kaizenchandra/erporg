# Official functional references consulted

Consulted 2026-10-21. These are workflow references, not licenses, connector availability, statutory rules, or product-parity claims. The user-pasted 90-ID baseline remains authoritative. All financial policies described as demonstration choices below are application decisions.

- [Workday: Get Started with Payroll](https://doc.workday.com/admin-guide/en-us/payroll/payroll.html): public guide separates payroll setup, components, country guides, payslips and accounting configuration. Used to keep country-specific processing distinct from a demonstration calculation.
- [Workday: Set Up Payroll Accounting](https://doc.workday.com/admin-guide/en-us/payroll/payroll-accounting-setup/dan1370796935174.html): inspected public page. Describes account sets, posting rules, fiscal schedules and ledger periods, reviewing accounting results and resolving posting/period errors. Used as a reference for explicit mapping, source traceability and recoverable closed-period rejection. Its automatic completion behavior is not adopted as a universal sequence: this application requires a separate accounting command, review and posting.
- [Workday Financial Management](https://www.workday.com/en-us/products/financial-management.html): public product overview describes transaction lineage, controls and close/consolidation. Used to distinguish the trial balance increment from the much broader accounting baseline.
- [Workday Accounting and Finance](https://www.workday.com/en-us/products/financial-management/accounting-finance.html): public reference page consulted; no tenant screens inspected.
- [SAP Employee Central Payroll features](https://www.sap.com/products/hcm/employee-central-payroll/features.html): public feature page describes control-center exception review, retro/off-cycle support and country localization. These remain explicit future implementation work here; no statutory formulas were inferred.
- [SAP: Posting Run](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE/749809c7d9fa45109f25cadf78827f31/9318dd5321e8424de10000000a174cb4.html) and [Posting to Accounting](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE/772870eb2306434f8dd1f225b704b8ee/5f3ac2531bb9b44ce10000000a174cb4.html): official search excerpts describe identified posting runs, progress/errors and payroll-result traceability. Direct dynamic pages returned no readable body in this environment, so only those excerpts were available; no full-page inspection is claimed.
- [SAP S/4HANA: Reversing Journal Entries](https://help.sap.com/docs/SAP_S4HANA_CLOUD/e2d057b7b4df44ba941a040d4dda2956/fbd0f1fe710d4e7fb413af2a7b62028a.html): official search excerpt describes selecting an original journal and confirming reversal details. The dynamic body was unavailable. The user's explicit preserve-history requirement, rather than undocumented vendor behavior, governs the implemented reviewed counter-entry.
- The supplied SAP Cloud payroll/finance link and attempted SAP finance feature page were also opened but yielded no readable body. No interface or credential-dependent capability was inferred from them.

Application-specific choices: demonstration-only USD/two decimal places, half-even hourly calculation from whole approved minutes, one fixed voluntary deduction, four illustrative ledger accounts, configured finite cost-centre codes, immutable monthly control revisions, mandatory three-person journal prepare/approve/post, no payment adapter, and no statutory output. They require business validation or replacement before production use.
